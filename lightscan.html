Puffco Light Scan

Helps Emberline learn how your Puffco’s lights work, so we can add controls for them. It only reads light settings, and only shows test colors when you tap a test. Nothing is changed for good, and no serial number is read.

1Connect

  1. Fully close the Puffco app (swipe it away). Only one app can talk to the Puffco at a time.
  2. Open this page in Path or Bluefy (iPhone), or Chrome (Android or computer).
Not connected

2First scan

Reads every light setting it can find. Takes about a minute, keep the phone close.

3Change the back lights, then scan again

  1. Open the Puffco app and change the back lights to something very different (for example bright red, or turn them off).
  2. Fully close the Puffco app again.
  3. Come back here, tap Connect again, then Scan again.

Comparing the two scans shows exactly which setting controls the back lights. You can repeat this with another color for an even better match.

4Color test

Shows a color for a few seconds using the same safe preview the Puffco app uses, then goes back to normal. For each one, tap which lights changed.

5Send it

Sends the scan to Emberline (no account, no serial number, just the light data and the device model). If sending fails, tap Copy and paste it in a DM instead.
